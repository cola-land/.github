## 组织构成

`cola-land` 组织托管 ColaLand 的站点与工程治理仓库：

| 仓库 | 职责 |
| --- | --- |
| `cola-land-main` | **主站**：页面布局、公共导航、账号入口与跨版面设计系统 |
| `cola-land-erlengshen-cars` | **二郎神车**分版面：车辆展示、检测维保、预约与交易流程 |
| `cola-land-qingzhong-institute` | **轻重咨诹处**：智库、研究报告与咨询委托分版面 |
| `cola-land-marxist-library` | **马列文库**分站页面与资源 |
| `cola-land-world-labor-court` | **世界劳工法庭**分站页面与资源 |
| `coland-mgmt` | **治理仓库**：端到端 QA + CI + CD 与管理 |

### 工程治理

- 站点模块以 **git submodule** 形式统一聚合在 `coland-mgmt/modules/`，一个版面一个仓库，独立演进、集中治理
- QA 基础设施收敛于 `coland-mgmt/qa/`，持续集成与持续交付流水线在 `coland-mgmt` 统一编排
- `main` 分支纪律：子模块指针持续跟进各模块 `main` 分支的 HEAD
